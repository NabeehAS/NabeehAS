## Featured Projects

### AI-Powered Feature Flag Undertaker
A Python developer tool for safely removing stale feature flags from codebases.

The project uses deterministic LibCST code transformations instead of unsafe regex rewriting, with automated validation using pytest. The main idea is to use AI for discovery and planning while keeping actual source-code changes deterministic, reviewable, and testable.

**Tech:** Python, LibCST, pytest, CLI tooling, Git

[View project](https://github.com/NabeehAS/feature-flag-codemod)

### LingoLamp — Generative AI Language Learning App
A mobile language-learning app that uses a chatbot, translation, grammar feedback, and flashcards to help users practice more naturally.

My main ownership was the chatbot flow and its connection to the flashcard system. One interesting challenge was extracting specific words and translations from natural LLM responses, which I solved using hidden markers that allowed the app to save vocabulary items with one tap.

**Tech:** Flutter, Firebase, Gemini API, Cloud Functions, Firestore

[View project](https://github.com/NabeehAS/LingoLamp)

### Deep Learning — Country Classification
A deep learning project focused on classifying countries from Google Street View images.

Developed CNN-based classifiers using ResNet50 and MobileNetV2, achieving around 75% accuracy on a 30,000-image dataset and improving predictions by about 5% over benchmark results. I also built an automated data collection pipeline using Google APIs to gather Street View images with balanced country representation.

The project included preprocessing, data augmentation, transfer learning, model training, evaluation, and hyperparameter tuning.

**Tech:** Python, PyTorch, TensorFlow, scikit-learn, Google APIs, CNNs, ResNet50, MobileNetV2

[View project](https://github.com/NabeehAS/DL_Project)
